## 編譯與執行

GCC 範例：
```sh
gcc -std=c11 -Wall -Wextra src/ex_2_23.c -o ex_2_23
./ex_2_23
```

Visual Studio：新增空白 C++ 專案，每次加入一個 .c 檔後執行。不要把九個 main 放進同一個專案一起連結。

2.32 使用 double 以保留小數；輸入單位是公斤與公尺，例如 60 與 1.7。
2.33 統一使用公里、公升，同一種貨幣；公式為「里程 / 每公升公里數 × 油價 + 停車費 + 通行費」。此程式估算自己開車的成本，不是共乘平台報價。
